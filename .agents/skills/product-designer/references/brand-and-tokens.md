# Brand and Design Tokens

Direction: contemporary, editorial, warm, creator-led. Current prototype colors are starting points, not validated brand standards.

| Token | Value | Purpose |
|---|---|---|
| ink | #071c19 | dark surface |
| forest | #123b2c | strong controls |
| leaf | #cdf66a | accent on dark |
| paper | #f7f8f4 | background |
| surface | #ffffff | cards |
| muted | #52665b | secondary text |
| border | #dae2dc | separators |

Use semantic CSS variables. Verify contrast per context: aim for WCAG AA 4.5:1 normal text and 3:1 large text. Use 4px spacing increments, readable fallback fonts, clear focus, responsive type and reduced-motion behavior.

Component inventory: navigation, category chips, search/filter, story card, creator attribution, language and country metadata, diversity slider explanation, category review, consent, empty/error states, accessible dashboard charts and tables.

Use creator-owned or properly licensed imagery with alt text. Avoid inferred cultural identity or unverified symbols.
