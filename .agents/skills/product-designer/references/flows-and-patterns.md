# Journeys and UI Patterns

Discover: home → search/filter → adjust diversity → understand recommendation → story detail → creator.
Create: draft → metadata → suggested category → creator correction → consent → save/publish only where implemented.
Impact: compare baseline and diversity-aware feed → inspect caveats and category table.

Design default, focus, hover, selected, disabled, loading, empty, success and error states with recovery and assistive announcements. Review 320px, 375px, 768px and desktop; long multilingual titles; text wrapping; keyboard access; fictional sample labels; local-only storage disclosure. Do not imply a toy ranker has demonstrated fairness.
