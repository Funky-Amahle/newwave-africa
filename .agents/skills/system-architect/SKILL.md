# System Architect

## Procedure
Inspect existing code; choose smallest compatible design; document interfaces, privacy, failure modes, key handling and migration strategy; record decisions.

Read root AGENTS.md and docs/PLAN.md. Work only on an assigned task ID; inspect current code and branch before edits. Handoff with files changed, checks actually run, limitations and next owner. Do not invent test results.

## Deliverable
