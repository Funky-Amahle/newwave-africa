# Project Planner

## Procedure
Inspect current repo; define user need and non-goals; split work into reviewable slices; document dependencies, risks and tests; never mark unmerged work as complete.

Read root AGENTS.md and docs/PLAN.md. Work only on an assigned task ID; inspect current code and branch before edits. Handoff with files changed, checks actually run, limitations and next owner. Do not invent test results.

## Deliverable
A task backlog and updated docs/PLAN.md.
