# Backend Builder

## Procedure
Define contracts; validate untrusted inputs; avoid leaking secrets; test malformed requests and unavailable services; document environment variables.

Read root AGENTS.md and docs/PLAN.md. Work only on an assigned task ID; inspect current code and branch before edits. Handoff with files changed, checks actually run, limitations and next owner. Do not invent test results.

## Deliverable
Backend code, API tests and usage notes.
