Eleven short synthetic narration previews using premade ElevenLabs voices. Afrikaans, isiZulu, Amharic, Swahili, Hausa, French, Arabic, Portuguese, Somali, Lingala and Shona. Playback does not generate audio again. Native-speaker review is pending; sample sentences are not all translations of one common script. No owner-cloned voice or API key is included.
