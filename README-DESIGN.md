# Product Designer Agent

Use .agents/skills/product-designer/SKILL.md for NewWave Africa product and visual design. Supporting references cover brand tokens, user journeys, accessibility and developer handoffs. Design tasks are in docs/design/DESIGN-PLAN.md. A separately packaged standalone ChatGPT skill is available in the conversation.

For interface reviews use [Design quality gate](docs/design/DESIGN-QUALITY-GATE.md), attach pass/fail/not-checked evidence, and hand off through [Agent Handoff](docs/AGENT-HANDOFF.md). Design documentation alone does not establish implementation or accessibility compliance.
