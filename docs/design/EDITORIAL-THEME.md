# NewWave Africa — Editorial Theme

Design direction: contemporary African cultural publication, not generic motifs. Story content and creator agency lead; brand uses ink #171714, paper #f3efe6, terracotta #c65a30, moss #495d4b. Monogram is a provisional geometric NW concept pending originality and small-size testing. Hero artwork is CSS geometry, not a cultural artifact or real creator portrait.

## Components
Brand: linked wordmark and inline SVG monogram. Hero: editorial typographic introduction and abstract CSS composition. StoryCard: consistent title, attribution, country, category and explicit fictional sample label. Existing discovery, creator studio and dashboard remain.

## Accessibility
Visible keyboard focus, semantic navigation, grouped workspace controls, pressed state, responsive 1/2/4-column cards, reduced-motion support, text alternatives for decorative hero. Manual WCAG contrast and assistive technology checks remain pending.

## Engineering
Next.js React TypeScript, Tailwind v4 PostCSS plus theme CSS. No new image licensing obligations; no external photography embedded. Build and typecheck require npm install and execution.
